# Medlink Backend (API)

This is the Node.js / Express backend for the Medlink Healthcare application.

For full project documentation, please refer to the [Main README](../README.md) in the root directory.

## Tech Stack
- **Node.js & Express**
- **MongoDB & Mongoose**
- **Cloudinary** (Image Uploads)
- **Groq/Gemini** (AI Services)

## Setup
1. `cd backend`
2. `npm install`
3. Configure `.env` (see Main README for keys).
4. `npm start`

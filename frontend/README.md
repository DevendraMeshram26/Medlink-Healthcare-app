# Medlink Frontend (Mobile App)

This is the React Native (Expo) frontend for the Medlink Healthcare application.

For full project documentation, including the backend setup and core features, please refer to the [Main README](../README.md) in the root directory.

## Features
- **Patient Portal**: Search, Discovery, Booking, AI Assistant.
- **Doctor Portal**: Dashboard, Appointment Management.
- **Modern UI**: Skeleton loading, role-based navigation.

## Quick Start
1. `cd frontend`
2. `npm install`
3. Configure `.env` with `API_BASE_URL`.
4. `npx expo start`
